# DEPTHSCAPE — Extended Parallax Journey

A 12-section, dependency-light parallax scrolling experience.

## Scenes
1. Arrival — mountains and moon
2. Forest — fog and layered trees
3. Canyon — mesas and rocks
4. Underwater — particles, kelp, fish and whale silhouette
5. Orbit — planets and orbital ring
6. Exoplanet — cratered alien landscape
7. Between — abstract geometric transition
8. After Dark — layered city skyline and rain
9. First Light — sunrise landscape
10. The Last Mile — aurora and snow
11. Return — warm morning landscape
12. Arrival — interactive final screen

## Run
Open `index.html`, or:

    python3 -m http.server 8000

Then visit http://localhost:8000

No build system or JS framework is required.
